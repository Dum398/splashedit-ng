One download per OS, with the editor, the example project, the psxsplash engine and pcsx-redux all included. Unpack it anywhere and start SplashEdit; nothing else needs installing.

- **Windows 10 or later:** `splashedit-windows.zip`, then run `splashedit.exe`. The executable is not signed, so SmartScreen may stop the first launch: More info, then Run anyway.
- **Linux x86-64, glibc 2.38 or newer** (Ubuntu 24.04, Debian 13, Fedora 39 and later): `splashedit-linux.tar.gz`, then run `splashedit`. `./install-desktop-entry.sh` adds it to your applications menu (run it again if you move the folder).
- **macOS on Apple silicon:** `splashedit-macos.tar.gz`, then open `SplashEdit.app`. The app is not notarized, so clear the download quarantine once before the first launch:
  `xattr -dr com.apple.quarantine splashedit`
